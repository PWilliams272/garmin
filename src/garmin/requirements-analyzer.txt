# Runtime dependencies for the analyzer/cache-build Lambda (lambda_analyze.py),
# deployed as a container image (infra/docker/analyzer.Dockerfile) rather than
# a zip -- scipy/scikit-learn/statsmodels alone are ~200MB+ uncompressed,
# well past a standard Lambda's 250MB unzipped code+layers limit.
#
# flask/myutils are only here because manual_build_viewer_cache.py imports
# garmin.app.routes to reuse its payload-building functions (so the cached
# and live-fallback payloads can't drift apart), and that module
# transitively imports garmin.data_processor.processor -> myutils at import
# time even though the analyzer never renders a page. Worth decoupling
# eventually (split routes.py's payload builders into a Flask-independent
# module) to shrink this image and its dependency surface; not done here.
# Pinned exactly (not >=) to versions verified to have prebuilt manylinux
# wheels compatible with this Lambda base image's glibc (Amazon Linux 2) --
# newer floating versions can resolve to a release with only a
# manylinux_2_28+ wheel, which AL2 can't use, forcing a from-source build
# that then fails with no C compiler installed.
# boto3/botocore aren't preinstalled here the way they are in the AWS-provided
# Lambda base image -- this uses a plain Debian base instead (see Dockerfile
# comment), so they need to be explicit.
